Deliverable 1 - CNN architecture design
● The goal is to learn how to design and train CNN networks to maximize mAP,
● The task is the multi-label classification on the Pascal VOC 2012 dataset,
● You can use the given code in the practical session as your base code.
○ Or reimplement it with your desired library (e.g. pytorch)
Evaluation Metric
● Primary:
○ Mean Average Precision (mAP) (VOC-style)
● Secondary:
○ Per-class AP and confusion matrix
○ Inference time (ms/image)
○ Model size (MB)

Deliverable 1 - Tasks
1- Analyze the dataset for the distribution of the labels by:
a. Counting the objects;
b. Counting the images, that is no matter how many objects of the same label appear on the
image, all counts 1;
c. Mean and variance of the area ratio (dividing object area to image area) of objects per label.
You can use object bounding box to compute the area.

Deliverable 1 - Tasks
2- Train a baseline CNN: implement VOC 2012 data loader and encode labels as
multi-hot vectors
● Architecture: ResNet-18
● Pretrained on ImageNet
● Loss: BCEWithLogitsLoss
● Optimizer: Adam
● Minimal augmentation (resize + normalize)

Deliverable 1 - Tasks
3- Architecture comparison: study accuracy vs efficiency trade-offs
● Same augmentation, optimizer, and training schedule as baseline
● Architectures to compare: ResNet-18, ResNet-50, MobileNetV3-Large, EfficientNet-B0
Questions:
● Does a deeper model always help?
● Which model gives best mAP / GPU-hour?
● Which struggles most with small objects?
● What about overfitting?
Select the best architecture and use it for the next experiments.
